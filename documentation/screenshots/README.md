# 📸 SoundGuard Dashboard Screenshots

This folder is designated for UI captures of the SoundGuard assistive monitoring dashboard.

---

## 🖥️ Primary Dashboard Views

1. **`overview_dashboard.png`** — Overview page displaying real-time detection counters, latest sound classification card, prediction confidence progress bars, and recent event timeline.
2. **`live_alert_strobe.png`** — Live Detection page demonstrating high-visibility flashing alert strobe beacon and tactile acknowledgement trigger when a critical alarm or door knock is detected.
3. **`detection_history_table.png`** — Detection History page showing multi-parameter filtering (category, date range, minimum confidence), sorting, pagination, and CSV data export.
4. **`sound_analytics_charts.png`** — Sound Analytics page displaying Recharts visualizations (category frequencies, proportion donuts, and 7-day activity timeline).
5. **`device_status_telemetry.png`** — ESP32 hardware diagnostics, real-time Wi-Fi RSSI signal meter, firmware version, and 30-second offline timeout indicator.
6. **`assistive_settings.png`** — Configuration panel for visual strobe triggers, audio chime synthesis, haptic vibration, and minimum confidence threshold enforcement.
